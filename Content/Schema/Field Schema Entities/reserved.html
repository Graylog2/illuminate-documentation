Reserved Fields

Reserved fields are top-level field names that are not prefixed by an entity name — they are used exactly as named on every normalized event. They are populated by Graylog itself (timestamp, message, source) or set directly by Illuminate content pack pipelines (sdm_version), and should not be reused or repurposed by pack authors for other purposes.

field field_type description example_values

message

text

Human-readable summary of the event - either the raw log line or a normalized summary populated by Illuminate content pack pipeline rules. This is a full-text analyzed field used for keyword search.

[Authentication] admin - Successful login from 10.1.2.3

sdm_version

keyword

Version of the Security Data Model (SDM) schema that this pack's normalized fields conform to, allowing consumers to determine which field definitions apply to a given message.

7.1.0

source

keyword/lowercase

Identifies the system or device that transmitted the message to Graylog (e.g. the sending host or collector), as distinct from the source_* entity fields, which describe the originating system or endpoint of the activity described in the event.

corpdc01.local, 10.1.2.3

timestamp

date

The primary timestamp of the event, populated from the original event time when available or the time of ingestion otherwise. This is the canonical time field used for time-range searches and event ordering in Graylog.

2026-07-28T14:32:10.123Z
