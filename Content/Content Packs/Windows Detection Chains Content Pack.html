Windows Detection Chains (Graylog 7.2) Content Pack

The Windows Detection Chains (Graylog 7.2) content pack provides Windows detection chains for Graylog 7.2 and later. It contains 74 detection chains and the 171 Windows detection rules (event definitions) that make them up. The rules focus on Windows security threats. They are configured to work directly with existing Windows Illuminate content like Windows Security, Sysmon, PowerShell, and Windows DNS.

Each detection chain tracks the detections observed in a real-world breach. A chain carries the breach context: a summary of the attack, the source of the analysis with a link to it, and, where available, the targeted technologies and industries.

This pack replaces the Windows Detection Chains Sigma Rules and Windows Detection Chains II Sigma Rules content packs. Both packs are no longer available. If you installed either pack, its rules move to this pack when you upgrade. Your notifications, search filters, and enabled state for these rules stay the same, so you do not need to disable or remove anything.

When you enable this content pack, the detection chains appear on the Detection Chains page and their rules appear on the Event Definitions page. By default, new rules are disabled. You can select which rules to enable for your environment.

Hint: Be sure to review the alerts before enabling them. Each rule can have a performance cost depending on your network configuration.

For best performance and to ensure accurate detection, you should enable at least one of these Windows content packs in addition to this Detection Chains pack:

  • Microsoft Windows Security

  • Microsoft Sysmon

  • Microsoft PowerShell

  • Microsoft Windows DNS

Warning: As the threat landscape evolves, rules can become obsolete, redundant, or less effective, necessitating their removal or revision. As such, the rules provided are subject to change and could be updated, modified, or removed in future updates. Users should regularly review and validate the latest versions to ensure they align with current security needs and best practices. 

Requirements

  • Graylog 7.2+
  • Graylog Security license
  • Windows Security, Sysmon, PowerShell, and/or Windows DNS content packs

Stream Configuration

This technology pack uses the stream category:

  • "windows_logs"

What Is Provided

This content pack includes 74 detection chains and 171 rules (event definitions). Each detection chain contains between 1 and 14 rules. 109 of the rules belong to at least one detection chain.

The rules have these priorities:

  • Critical priority: 19 rules

  • High priority: 96 rules

  • Medium priority: 43 rules

  • Low priority: 13 rules

Each rule includes a description of what it detects and the MITRE ATT&CK techniques it covers.

Configure Detection Chain Rules

When you enable this content, the detection chains are added to the Detection Chains page and their rules are added to the Event Definitions page in Graylog. Follow the steps below to enable rules and configure alerts.

  1. Review the detection chains on the Detection Chains page. Each chain shows the breach context and the rules that make it up.

  2. Enable your chosen rules on the Event Definitions page (Alerts > Event Definitions).

    Hint: To find the rules added by this content pack, search for Illuminate. At the end of the rule name is (Detection Chain).

    Hint: Be sure to review the alerts before enabling them. Each rule can have a performance cost, depending on your network configuration.

  3. Update rules if necessary. Some rules can result in many false positives and should be adjusted. For the rules you enable, review the event definitions. You can add search filters or alerts as well as custom fields.

    Hint: No rule in this pack sends alerts or notifications by default. Add a notification to the event definitions you want to be alerted on.
