Configure Security Core

Graylog Security Core aims to be as easy to use as possible. To get the most out of the content, it is recommended to configure it correctly. This includes enabling alerts and adding notifications, adjusting report styles and schedules to fit your needs, and applying context to ensure the packaged detections fire on the right resources.

Configuration Steps

  • Enable alerts and add notifications to receive alerts externally.

  • Adjust report styles and schedules to fit your needs.

  • Apply context with the asset model and lookup tables.
