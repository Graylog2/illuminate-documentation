Leveraging Lookup Tables

Lookup tables are used in places that require context but are not currently part of the asset model. Lookup tables used in Security Core are referenced at search time (when the query is run). This means they use a single key whose values are concatenated into it.

Lookup Tables

Lookup Table Name Key Description
Monitored Ports port CSV-separated list of ports to monitor
Monitored IPs ip CSV-separated list of IPs to monitor
Monitored Geolocations country_iso CSV-separated list of geolocations to monitor
Monitored Domains domain CSV-separated list of domains to monitor
Monitored Groups group CSV-separated list of groups to monitor
Monitored Roles role CSV-separated list of roles to monitor
Monitored Files file CSV-separated list of files to monitor
core_networks_adapter Pipe-separated list of tags to apply for a network range

Configuring Lookup Tables

To configure these tables, they can be found within the Enterprise > Illuminate > Customisation menu with the names listed above.

As an example, configuring the core_networks_adapter to add the tags "acme_local" and "is_internal" to any event coming from or going to the network range "192.168.92.0/26" will place them in the source_category and destination_category fields.
