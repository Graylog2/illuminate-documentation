What is Security Core

Graylog Security Core is an Illuminate content pack available via the Illuminate Content Hub and provides foundational, product-agnostic, out-of-the-box security content. It includes over 100 distinct content items, spread across alerts, dashboards, and reports, all aligned with the MITRE ATT&CK framework. All content is built using standard Graylog queries utilising Search Filters.

Content is designed to cover 7 distinct attack surfaces: Identity, Endpoint, Perimeter, Web, Data, Cloud and Malware. However, it is not limited to any specific data source, and all content and query requirements are fully documented to enable integration with custom data sources.

Getting Started

  • Install Security Core for the first time or upgrade your existing content.
  • Configure Security Core
    • Enable alerts and configure notifications to receive alerts externally
    • Customise reports and report schedules to ensure reports run when you desire
    • Apply context with the asset model and lookup tables.
  • Tune Security Core
    • Reduce alert noise by removing false positives, suppressing alerts and suppressing notifications.
